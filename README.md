# DFA 语言代数与最短见证

对几份独立产生的有限状态规则（DFA）做语言级比较与运算：交、并、差、补、
最小化，以及等价 / 包含判定（失败时给出最短、可复核的见证 token 序列）。
**不解析正则表达式**，只用 Python 3 标准库。

## 运行环境与命令

- Python 3.14.7 标准库，Windows 原生，无第三方依赖。
- 演示（约 0.2 秒，含一个等价的正常结果和一个实际触发的不等价失败）：
  ```
  python demo.py
  ```
- 测试：
  ```
  python -m unittest discover -s tests -v
  ```

## 接口

文件 `dfa_algebra.py`。

### DFA 构造

```python
from dfa_algebra import DFA
d = DFA(states=[0, 1, 2],
        alphabet=["a", "b"],          # 字符串 token，按字典序保存，可空，至多 8 个
        start=0,                      # 初态，必须在 states 中
        accepting=[1],                # 接受态集合
        transitions=[(0, "a", 1), ...])   # 三元组列表；也接受 {(src, tok): dst} 字典
```

- 状态 id 只能是整数（`bool` 拒绝）；未知状态引用、空 states、重复字母、
  重复转移、token 不在字母表等均抛 `DFAError`。
- 转移表允许不完整：**缺失的 `(状态, token)` 转移视为进入隐式拒绝汇点**；
  机器未声明的 token 同样进入汇点。汇点不是合法外部 id，内部为常量 `SINK`。
- 输入限制：外部导入 DFA 至多 **80** 个状态；字母表至多 **8** 个 token
  （常量 `IMPORTED_STATE_LIMIT` / `ALPHABET_MAX`）。
- 语言运算结果允许超过 80 态；单次运算探索至多 **10000** 个可达状态
  （`MAX_REACHABLE_STATES`）。只在 BFS 真正需要第 10001 个新状态时抛
  `DFALimitError`，**不**预先按笛卡尔积总大小拒绝稀疏乘积。

### 语言运算（双方字母表先取并集并按字典序统一）

```python
intersect(a, b)     # L(A) ∩ L(B)
union(a, b)         # L(A) ∪ L(B)
difference(a, b)    # L(A) \ L(B)
complement(a)       # Σ* \ L(A)，Σ 为 A 的显式字母表
```

补集相对于显式字母表上的全部有限串；**空字母表时 Σ* = {ε}**，补集只按
初态接受性取反。补集使隐式汇点（若可达）成为接受态。

### 最小化

```python
r = minimize(d)
r.dfa              # 最小完整 DFA：只含可达态，初态 0，按 token 顺序 BFS 编号
r.mapping          # 原可达状态 id -> 最小状态 id
r.sink_state       # 隐式汇点所在最小状态 id；不可达为 None
r.sink_reachable   # 隐式汇点是否可达
```

采用 Hopcroft 分割细化（产生真正最小的完整 DFA），随后从初态出发按 token
字典序 BFS 重新编号。映射只含**可达**状态（不可达态被删除）；隐式汇点若
可达，映射中含键 `SINK`（值为 -1），与语义相同的显式非接受陷阱态会合并。

### 执行与判定

```python
run(d, ["a", "b"])              # 逐步执行，返回 bool；未知 token 按进汇点处理
equivalent(a, b)                # 语言是否相同
subset(a, b)                    # L(A) 是否包含于 L(B)
witness_inequivalent(a, b)      # 不同则返回见证 token 列表；等价返回 None
witness_not_subset(a, b)        # L(A)⊄L(B) 时返回 A 接受 B 拒绝的见证；否则 None
```

- 见证是产品状态图上的 BFS 结果（**不是**按固定长度枚举字符串）：长度最短，
  同长度按 token 序列字典序最小。
- **空列表 `[]` 是合法见证 ε**（例如初态接受性不同）；无见证返回 `None`，
  两者严格区分。见证返回前会在双方机器上重新执行并核对接受性。
- 产品图搜索同样受 10000 可达状态上限约束。

## 测试覆盖（27 个用例）

- 输入校验：未知状态引用、重复字母 / 转移、非整数状态（含 bool）、
  超 80 态、超 8 token、空 states。
- 运算正确性：60 组固定随机种子（`random.Random(20260920)`）小 DFA，
  对长度 ≤5 的全部串逐点核验交 / 并 / 差 / 补；等价与包含真值由独立的
  产品对闭包参考实现给出，见证再与独立分层枚举结果比对（最短 + 字典序）。
- 最小化：删除不可达态、合并等价态、BFS 编号顺序、汇点可达映射、
  汇点与显式陷阱合并；40 组随机机最小化后用**区分后缀**对每对状态验证
  可区分性，并再次最小化验证状态数不变。
- 边界：全接受 / 全拒绝、空字母表（{ε} 与 ∅）、ε 空串反例、不同字母表、
  缺转移、不可达状态；大结果（1600 态乘积）的最小化与查询。
- 限制：笛卡尔积超过 10000 但实际可达稀疏的乘积不报错；实际需要超过
  10000 个可达状态时运算与见证搜索均抛 `DFALimitError`。

## demo 说明

- 场景一：两台独立产生、字母表不同、含冗余 / 不可达状态且转移不完整的
  机器描述同一语言（“含 a 且不含 c”），产品图无见证（返回 None），并用
  1093 条短串穷举复核。
- 场景二：另一台只接受 `["b"]` 的机器与它不等价，产品图 BFS 给出最短
  见证 `["a"]`（同长度字典序最小），在双方实际执行核对接受性；两个方向
  的包含反例分别为 `["a"]` 与 `["b"]`，并与独立穷举参考实现比对一致。
